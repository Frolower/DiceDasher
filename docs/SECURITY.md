# Security Policy

DiceDasher is an early-stage, open-source project. While we try to follow reasonable security practices, the project has not been formally audited.

## Supported Versions

Only the `master` branch is currently supported.

## Reporting a Vulnerability

If you believe you’ve found a security vulnerability, please report it **privately**.

### Preferred reporting method

- Contact the maintainer via [GitHub profile](https://github.com/Frolower)
  (Please include “SECURITY” in the message subject/title if possible.)

If private contact is not possible, you may open a GitHub issue, but **please avoid including exploit details**. A maintainer may ask you to move details to a private channel.

### What to include

Please include:
- A description of the vulnerability and potential impact
- Steps to reproduce (proof of concept if possible)
- Affected component(s) (service name, endpoint, file/path)
- Any mitigation ideas or a proposed fix (optional)

### Disclosure guidelines

Please **do not disclose the vulnerability publicly** until:
- a fix is released, or
- we confirm the issue is not exploitable / out of scope.

We will:
1. Acknowledge receipt of your report when we see it
2. Evaluate and prioritize the report
3. Publish a fix or mitigation (if applicable)
4. Credit you for the report if you’d like

## Security-related issues not covered

This repository does not currently run a bug bounty program.
